# Gödel Ontological Proof

- I use Rocq

## Main version

In Gödel_God.v:

- I declare Law Of Excluded Middle
- I define Modal Logic operators and declare Modal Logic Axioms S5.
- In graph terms, S5 characterizes frames that form an undirected graph made of separate connected components
- I declare Gödel's "P" - Positive Higher Order Predicate
- I define Gödel's "G" - Godlike figure
- I define Gödel's "esse" - Essential property
- I define Gödel's "E" - Nessesary existence
- I declare Gödel Axioms
- I prove that from all these axioms and definitions, you can deduce that $\exists ! \; x, \Box \ G(x)$. This means that in each adjacent component of the graph all of the Modal Logic Kripke worlds, there exists unique Godlike figure
